## About NeverDOM

**NeverDOM** is an independent technology studio founded by **Smit Patel**. We build useful web products, explore new digital infrastructure ideas, and turn everyday problems into simple, accessible tools.

NeverDOM is the parent brand—not only a hosting service. Hosting is one part of a broader ecosystem that includes productivity tools, document utilities, web infrastructure experiments, and new platform concepts.

## What We Are Building

| Project | Purpose | Status |
|---|---|---|
| **NeverDOM Hosting** | A simple hosting experience with account management, domains, authentication, and support tools | In development |
| **HisabGo** | Shared expense, balance, and budget tracking with permission-based family or group access | Planned |
| **DLDS** | Daily-life document tools for transcription, translation, PDF workflows, and other document tasks | Research & development |
| **YFTP** | A browser-based interface for accessing and managing supported FTP resources | Concept |
| **NeverDOM Browser Ecosystem** | An experimental environment for internal services, discovery, and alternative naming concepts | Research |
| **OMT** | Exploration of secure offline transaction and verification concepts | Research only |

> Status labels are intentional: this repository does not present planned or experimental work as a finished product.

## Current Focus

- Creating a clear and consistent NeverDOM product ecosystem
- Building fast, mobile-friendly web applications
- Designing secure authentication and account flows
- Improving hosting tools and user dashboards
- Exploring progressive web apps and real-time notifications
- Prototyping useful ideas before turning them into products

## Product Principles

1. **Useful before impressive** — solve a real problem first.
2. **Simple by design** — make important actions easy to understand.
3. **Security from the beginning** — protect accounts, data, and permissions.
4. **Honest project status** — clearly separate live, developing, and experimental work.
5. **Build sustainably** — test value before spending heavily or scaling.
6. **Keep improving** — release, learn, refine, and repeat.

## Project Status

NeverDOM is currently in **early development**. Features, architecture, project names, and availability may change as ideas are tested and improved.

For production use, rely only on services explicitly marked as live on the official website.

## Security

Please do not publish passwords, API keys, access tokens, private customer data, or security vulnerabilities in a public issue.

If you discover a security problem, contact NeverDOM privately through the official website:

**[neverdom.com](https://neverdom.com)**

## Contributing

NeverDOM is currently founder-led and this repository is private. Collaboration guidelines will be added when external contributions are opened.

For now, approved collaborators should:

1. Create a focused branch for each change.
2. Keep commits small and clearly described.
3. Never commit secrets or personal data.
4. Test changes before requesting review.
5. Document any new configuration requirements.
